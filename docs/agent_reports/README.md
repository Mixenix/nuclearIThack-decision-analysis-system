# Отчёты исполнителей (исторические)

Это **снимки состояния на момент работы**, а не актуальная документация. Здесь могут
встречаться значения, которые с тех пор изменились: старые IP-адреса, идентификаторы
прогонов, счётчики тестов (набор рос: 280 → 310 → 339).

Актуальные факты — в корневом `README.md`, `docs/STATUS.md`, `docs/BENCHMARKS.md` и
`docs/AUDIT.md`; они сверяются с базой командой `tools/check_doc_claims.py`.

| Файл | О чём |
|---|---|
| `lead.md` | ход работ ведущего исполнителя |
| `docs-bench.md` | чистая установка и замеры |
| `llm-report.md` | блок независимого мнения ИИ |
| `qa-tests.md` | набор тестов и его качество |
| `ui-verify.md` | проверка интерфейса в браузере |
