## Что НЕ проверено (честный список)

1. **Браузерные сценарии «глазами пользователя»** — страницы отдают 200 и поднимаются без
   ошибок в журнале, но клики/скачивание файла/два пользователя в двух браузерах
   проверяет отдельный агент; результат — в `agent_reports/ui-verify.md`.
2. **GPU-режим** — не устанавливался и не измерялся (`BENCHMARKS.md §5`).
3. **Установка на чистой второй машине** — команды README проверены на этой машине
   (включая установку в пустое окружение), но прогон на другой ОС/железе не делался.
4. **Качество ответа LLM** — интеграция проверена (DONE + запись в БД), но содержание
   ответа модели не проверяется детерминированно и не влияет на числа отчёта.
5. **Масштаб 20 000 заявок** — не запускался.
6. **Одновременная нагрузка двух пользователей с числами** — только качественная проверка.
